# 简繁中文验证记录

验证日期：2026-10-23。使用 ESP-IDF 5.5.5，动态应用 ABI 101。

## 实施范围

系统、49 个原生应用翻译目录、管理网页和 24 个应用网页均提供 `zh-Hans` / `zh-Hant`。每种中文共 75 份目录。50 个动态应用中的 Blit test 为颜色与传输测试，无独立界面文案目录。

简体使用 Noto Sans SC 字形与 `zh-CN` 网页区域格式，繁体使用 Noto Sans TC 字形、台湾常用软件术语与 `zh-TW` 格式。切换会保存偏好并重建界面；网页等待设备确认切换完成，检测到外部语言变化时保护未保存编辑。旧存储卡网页仍可使用原有翻译接口。

## 板载资源

字库位于 Flash 的 `storage` 分区（`0x1000000`，12 MiB），无需 SD 卡。镜像含 20,501 个区域字形记录，总大小 11,890,612 字节；完整资源校验后，板端索引与 128 字形缓存占 156,756 字节 PSRAM。字形按需从 Flash 读取。

首次安装必须完整串口烧录 `cjk.bin`。后续仅更新应用固件的 OTA / `app-flash` 会保留原字库；若资源指纹变化，应再次完整烧录。详见 [I18N.md](I18N.md)。

## 自动检查与板端结果

- Python：6 项测试通过，无跳过。覆盖源文格式参数、翻译键与换行、字体 SHA-256 / CRC / 字形覆盖、压缩目录、内嵌网页资源，以及实际编译的 RISC-V UTF-8 换行与截断测试。
- Node：16 项测试通过，覆盖内置与 SD 覆盖翻译、简繁区域格式、网页目录隔离及旧接口兼容、切换确认和失败处理，以及此前触摸边界和上传错误处理的回归检查。
- `gen_lang.py check zh-Hans` 和 `check zh-Hant` 均通过。
- COM24 的 Waveshare 10.1 英寸实机（ESP32-P4 v3.2）通过字库校验，启动诊断成功加载 98 份简繁原生目录，并渲染两套区域字形；随后恢复原来的 `zh-Hans` 偏好。
- 用户实测确认：简体与繁体中文的主屏幕、设置、日期显示和语言切换均正常。

## 验证边界

四种板型与两种芯片配置的构建和 ABI 检查不能替代逐台实机测试。目前只有 COM24 的 10.1 英寸板参与板端验证，未逐一运行全部动态应用，也未完成 SDL 模拟器整机运行。

设备管理网页的自动实机操作受浏览器安全策略限制；网页语言行为以离线执行实际 JavaScript 的测试验证。文件上传实机测试按用户要求暂不进行。

中文资源包含本地模型草稿与已审校的界面术语、常用操作及技术说明；长篇帮助和游戏叙事仍需持续人工审校。覆盖和格式测试不代表每句文案均已通过人工语言质量认证。
