# 中文与离线字库

P4OS 的语言选项包括西班牙语、英语、德语、简体中文（`zh-Hans`）和繁體中文（`zh-Hant`）。中文翻译随固件提供，中文字库位于板载 Flash，不需要 microSD 或在线翻译服务。

## 使用

在设备的“设置 → 语言”中选择中文，也可以在管理网页的“设置 → 语言”中切换。设备保存语言选择，重启后继续使用。切换会关闭打开的应用；具有后台任务的应用会按原有生命周期重新启动。

网页的菜单、登录页和应用管理页使用设备语言。设备语言从另一处更改后，没有编辑内容的网页会自动刷新；有未保存编辑时会提示保存后刷新。网页发起切换时会等待设备确认，失败时显示错误，不再使用固定延迟刷新。

简体和繁体使用各自的 Noto Sans SC/TC 字形。繁体采用台湾地区常见的软件用语，日期和数字格式使用 `zh-TW`；简体使用 `zh-CN`。天气搜索也使用设备语言。设置页提供上海、台北和香港时区。

## 首次安装与升级

完整串口烧录包含 `cjk.bin`。只更新应用固件的 OTA 或 `app-flash` 不会安装或更新字库。首次启用中文，以及升级后提示字库不匹配时，请通过 USB 安装完整包。

以已配置的 10.1 英寸、rev3_x 构建目录为例，在 ESP-IDF 环境中执行：

```powershell
idf.py -B build/lcd10_1/rev3_x -p COM24 build flash
```

新建构建目录的板型和硅版本配置见 [BOARDS.md](BOARDS.md)。完整发布 ZIP 中也包含 `cjk.bin`，必须保留文件布局并使用随包提供的 `flash_args`。

字库使用现有 `storage` 分区，偏移 `0x1000000`，容量 12 MiB。分区保留原来的名称、偏移与类型，内容为只读字体资源，不挂载为 FAT 文件系统。烧录无需清空 NVS，也不需要格式化存储卡。

固件检查字库版本、大小、顺序和 CRC，并与编译时的资源指纹匹配。资源缺失或损坏时不会切换到无法显示的中文，也不会因该失败关闭正在运行的应用；设备会提示安装完整包。

## 覆盖与内存

- 每种中文有 75 个目录文件，覆盖系统、49 个原生应用目录，以及管理网页与 24 个应用网页目录。
- 字库包含界面文字、全角标点及 GB2312/Big5 常用字，涵盖常见简繁中文内容；不是整个 Unicode 字库。
- 字形为 48 像素、2 位灰度，小字号缩小时进行覆盖率采样。简繁字形分别索引，不会因切换后沿用缓存而混用字形。
- 字库从 Flash 按需读取，PSRAM 只保留索引与 128 个字形的缓存。缓存访问加锁，支持固件的两个绘制线程。
- 像素画布应用增加 UTF-8 解码、中文宽度计算和共用字形绘制，动态应用 ABI 仍为 101。

板载翻译可按键被存储卡上的同名语言包覆盖。若使用过旧的自定义语言包，请同时检查其中的文字，避免覆盖新的内置修订。

## 维护与生成

源文件为 `lang/zh-Hans/` 和 `lang/zh-Hant/`。常用术语的人工修订在 `lang/zh-overrides.json`，有语境差异的整句修订在 `lang/zh-key-overrides.json`。中文资源由本地模型草稿与人工修订组成；长篇应用说明和游戏叙事仍需持续审校，不能把自动覆盖检查当作逐句语言质量认证。

修改翻译后重新生成内置目录：

```text
python tools/gen_lang.py embed en de zh-Hans zh-Hant
```

构建固件不需要下载模型或字体：已生成的字体镜像、清单和许可证均在 `assets/cjk/`。重新生成字库需要 Pillow 13、fonttools，以及 Noto Sans SC/TC 字体：

```text
python tools/gen_cjk.py --fonts build/chinese-fonts
```

字体目录包含 `NotoSansSC.ttf`、`NotoSansTC.ttf` 和 `OFL.txt`。字库清单记录字体 SHA-256、字形集合及镜像 SHA-256。生成器会同时更新 `aos_cjk_resource.h`；字体镜像和该头文件必须一起提交与构建。

字体来自 [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 与 [Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)，使用 OFL 1.1；许可证随字库保留。可选的 `tools/translate_zh.py` 仅在开发机运行，固件不包含模型，也不会调用翻译网络服务。维护时应保留格式参数、换行、型号、接线和数值，并优先审查技术说明。

## 验证

```text
python -m unittest discover -s tests -p test_chinese.py
python -m unittest discover -s tests -p test_web_assets.py
python -m unittest discover -s tests -p test_utf8_native.py
node --test tests/test_portal_language.cjs tests/test_portal_web.cjs
python tools/gen_lang.py check zh-Hans
python tools/gen_lang.py check zh-Hant
```

自动检查覆盖目录键、格式参数、换行、字库覆盖、镜像完整性、离线网页语言、语言切换延迟与错误处理。实际屏幕上的排版、触摸操作与游戏画布仍需在设备上检查。构建通过与静态 ABI 兼容性不等于所有应用都已逐一完成实机测试。

UTF-8 原生测试可使用本机 C 编译器；Windows 上也可在 ESP-IDF 环境中安装测试依赖 `unicorn`、`pyelftools`，执行真实 RISC-V 编译结果。它覆盖中文换行、逐字显示、截断边界和异常编码。

## 板上自检（开发验证）

`-D AOS_I18N_SELFTEST=ON` 可启用默认关闭的启动自检。它在界面创建前加载简繁两套系统目录、逐个检查原生应用目录，并从 Flash 读取同一字符的两套区域字形；结束后恢复原语言偏好。串口日志中的 `i18n-test: PASS` 才表示通过。

验证完成后须用 `-D AOS_I18N_SELFTEST=OFF` 重新构建并安装正式固件。发布固件保持关闭该选项；自检不等于所有应用已在真实屏幕逐一完成目视测试。

Truco 的菜单、比分和操作已本地化，游戏规则与联机协议保留规范名称。Blit test 仅为颜色与传输测试，没有需要单独翻译的应用界面文字。
