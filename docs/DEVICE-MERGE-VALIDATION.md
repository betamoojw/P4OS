# COM24 合并固件实机验证

日期：2026-10-23。开发板：Waveshare ESP32-P4-WIFI6-Touch-LCD-10.1；COM24 芯片读取为 ESP32-P4 v3.2。

后续修复与重新烧录结果见 [网页与诊断修复验证](DEVICE-FIXES-VALIDATION.md)。以下保留首次验证时的发现，不能将当时的待修复项视为最新状态。

基于提交 `4cbf450` 重新构建正式 `lcd10_1/rev3_x` 固件，版本 `v0.15.0-114-g4cbf450`，关闭设备自测。应用 7,053,072 字节，应用分区约剩余 15%。完整串口烧录引导程序、分区表、OTA 初始信息、应用及 `cjk.bin`，各段哈希校验通过，保留 NVS 设置。

## 已取得的实机证据

- 启动成功，32 MiB PSRAM 检查通过，显示与触摸初始化成功，字体加载 20,501 个区域字形。
- 设备恢复原 Wi-Fi 连接，地址 `192.168.71.120`；管理页确认新固件版本和 10.1 英寸板型。
- 网页切换 `zh-Hans → zh-Hant → zh-Hans`，设备日志均确认应用语言，网页导航和设置随之更新；屏幕镜像观察到两套中文字形。
- 管理页打开设备设置、主页、返回和方向控制可用。用户确认此前也在操作设备，停止同时操作后，重新测试远程轻触和下拉控制中心可用。
- 动态壁纸可以选择并显示在主页；本次没有跨全天验证所有时段配色。
- 控制中心显示“录屏”入口；无卡尝试后状态为 recording=false、frames=0、bytes=0、file为空、last_ok=false。未证明 MP4 成功录制。

## 限制与发现

- 当前没有 microSD，不能完整验证录屏文件、照片壁纸或新增管道拼图动态应用运行；没有上传文件，遵循此前用户要求。
- 网页存在方向切换后的异步导航竞争：切换方向后立即跳到“屏幕”，延迟的设置页刷新可能覆盖当前内容。刷新页面恢复。源码中方向按钮使用延迟 pageAjustes 回调，未核对当前路由。
- 部分既有翻译不自然，应用选择器仍使用西班牙文名称；纵向镜像的旁栏中较长板型名称使“开发板”标签挤成多行。不能据本次检查宣称语言质量与布局全部无问题。
- 启动报告 ESP-Hosted 主端 3.0.9 与 C6 2.12.13 主版本不一致，联网仍成功；未更改 C6 固件。
- 观察到一次 I2C 总线探测超时；需结合后续测试判断是否重复，不能据此认定硬件故障。

## 收尾结果

主题色已从蓝色切换为紫色并恢复蓝色，选中标记响应正常。键盘音效开关可开关并恢复关闭，系统音效保持开启；触发了扬声器测试，但用户不方便确认实际声音，因此听音结果仍未验证。

Wi-Fi 页面确认已连接；固件页确认运行 ota_0、ELF 前缀 `29f7837cc9694f01`，没有保存的崩溃记录。固件页仍提示旧的 `build/rev1_3/p4os.bin` 路径，不适用于当前 v3.2 的 10.1 英寸板，应修正为板型及硅版本对应路径。当前实际烧录使用正确的 `build/lcd10_1/rev3_x/p4os.bin`。

十分钟串口观察未出现 panic、看门狗或非预期重启。测试结束恢复简体中文、横向、黑色壁纸、蓝色主题、亮度 78、音量 100 和键盘音效关闭。最后重启再次成功加载字体、保留 zh-Hans 并获取相同 IP。

本次没有修改固件源码，也没有再次提交或推送；发现的问题为待修复项。本报告不能视为所有新增功能均已通过验收。相机优化尚未实测；无卡项目和声音实际输出也仍待补测。
